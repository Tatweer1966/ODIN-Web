# JCWS Sprint 2C - Operational Map Workspace

Implemented:
- Real OpenLayers operational map route at `/workspace`
- Layer manager with visibility, locking and opacity
- BLUEFOR and REDFOR sample force tracks
- Operational control measures and working graphics
- Point, route, polygon and circle drawing tools
- Zoom, reset and coordinate tracking
- Tactical summary and object inspector shell
- Responsive map workspace layout

Build:
```powershell
npm install --workspace frontend
npm run build --workspace frontend
```
